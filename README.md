# pizza-sales-analysis-sql
SQL-based sales analysis project on pizza orders data. Covers revenue, best-selling pizzas, order trends, and more using MySQL.

## Dataset
4 tables: orders, order_details, pizza_types, pizzas

## Tools Used
- MySQL / SQL
- CSV datasets

## Analysis Covers
- Total revenue and order volume
- Best and worst selling pizzas
- Peak order hours and days
- Revenue by pizza category and size

## How to Use
1. Import the CSV files into your MySQL database
2. Run the queries in `pizzasprojectsql.sql`
